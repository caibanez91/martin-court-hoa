# Martin Court HOA — Financial Dashboard

Interactive financial dashboard for the Martin Court Property Owners Association community meeting (April 2026).

## Live Dashboard

**[View the Dashboard](https://ceibanez91.github.io/martin-court-hoa/)**

## Features

- **Financial Overview** — Year-over-year P&L trends, cash/equity tracking, expense distribution charts
- **Per-Household Breakdown** — Shows exactly how each dollar of monthly dues is allocated across expenses
- **Budget vs Actual** — Q1 2026 performance against approved budget with variance analysis
- **What-If Scenarios** — Interactive sliders and inputs to model different dues amounts and expense levels
- **Cost Savings Plan** — Phased approach to minimize dues increases through vendor optimization and fee reduction
- **Water Payoff Plan** — Installment calculator with adjustable balance and timeline
- **Collections Tracking** — Accounts receivable aging detail by owner

## Tech

Single-file HTML application using React 18 and Recharts, loaded via CDN. No build step required — just open `index.html` or deploy to GitHub Pages.

## Data Sources

All figures sourced from QuickBooks P&L statements, balance sheets, bank transaction records, and AR aging reports for Martin Court Property Owners Association Inc.
